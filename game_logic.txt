GenOS Game Logic Pseudocode - Updated November 2025

This pseudocode tracks the internal logic of Snake and Tetris in GenOS.
Both games now use VGA Mode 13h (320x200, 256 colors) for consistent rendering.

================================================================================
KERNEL INITIALIZATION
================================================================================
1. Setup stack pointer at 0x7000 (8KB stack space)
2. Disable interrupts (cli)
3. Initialize interrupt system:
   - Setup IDT with 256 entries
   - Setup timer interrupt handler (IRQ0)
   - Setup keyboard interrupt handler (IRQ1)
   - Initialize PICs
   - Initialize PIT 
4. Switch to VGA Mode 13h 
5. Game Selection:
   - Clear screen & draw menu
   - Enable interrupts
   - Wait for input (1=Snake, 2=Tetris)
   - Jump to game

================================================================================
TETRIS GAME
================================================================================
Constants:
   BLOCK_SIZE = 8 pixels
   GRID_WIDTH = 10 (columns 0-9)
   GRID_HEIGHT = 19 (rows 0-18)
   PLAY_AREA_X = 120
   PLAY_AREA_Y = 20
   PLAY_AREA_BOTTOM = 172

Data:
   tetris_grid[190] // 19×10 grid: 0=empty, 1=filled
   current_x_index  // Column 0-9
   current_y_index  // Row 0-18
   current_piece_x  // Pixel X
   current_piece_y  // Pixel Y
   last_drawn_x/y   // For erasing

Initialization:
   - Clear screen & draw HUD
   - Reset stack to 0x7000
   - Set: y=20, x=160, x_index=4, y_index=0

Main Loop:
   if paused: goto pause_handler
   wait_frames(5)
   
   loop:
      if paused: goto pause_handler
      wait_frames(6)
      
      erase_block(last_drawn_x, last_drawn_y)
      tmp_y = current_piece_y + 8
      
      if tmp_y >= 172:
         goto bottom_block
      
      current_piece_y = tmp_y
      last_drawn_x = current_piece_x
      last_drawn_y = tmp_y
      draw_block(current_piece_x, tmp_y)

Bottom Block:
   draw_block(current_piece_x, current_piece_y)
   y_index = (current_piece_y - 20) / 8
   x_index = current_x_index
   offset = (y_index * 10) + x_index
   tetris_grid[offset] = 1
   check_line_complete(y_index)
   goto next_block

Next Block:
   current_x_index = 4
   current_piece_x = 152 (center)
   current_piece_y = 20
   last_drawn = same
   draw_block()

Line Check:
   count filled cells in row
   if count == 10: line complete!

Keyboard (Tetris):
   A: if x_index > 0: x_index--, recalc pixel X
   D: if x_index < 9: x_index++, recalc pixel X
   SPACE: toggle pause
   ESC: return to menu

================================================================================
SNAKE GAME 
================================================================================
Constants:
   BLOCK_SIZE = 4 pixels
   GRID = 80×50

Data:
   snake_x[100], snake_y[100] // Circular buffer
   snake_head, snake_tail, snake_len
   current_direction
   food_x[10], food_y[10], apple_count

Initialization:
   - Start: x={40,41,42,43}, y={25,25,25,25}
   - head=3, tail=0, len=4, dir=RIGHT

Main Loop:
   if paused: pause_handler
   
   while apple_count < 10: spawn_apple()
   
   display_length()
   
   new_x = snake_x[head] + delta_x
   new_y = snake_y[head] + delta_y
   wrap_screen_edges()
   
   snake_head = (head + 1) % 100
   snake_x[head] = new_x
   snake_y[head] = new_y
   
   if ate_apple:
      snake_len++
   else:
      erase tail
      snake_tail = (tail + 1) % 100
   
   draw head
   wait_frames(3)

Keyboard (Snake):
   WASD: change direction (no 180° turns) // though theres a race where one can move 90°+90° in one frame that looks like a single 180° turn, though cba to fix it...
   SPACE: pause
   ESC: menu
